# Noetrail 0.10.0a6

This alpha fixes redundant bare image paths in marker-configured outbox replies.
The current core schema is 12; no migration is needed from 0.10.0a5.

## Changes

- With `--attachment-outbox` and a marker template, `get_attachment` returns
  the complete `delivery_marker` and omits `delivery_path` from both text
  content and `structuredContent`. No inline image block is returned. This
  prevents a second, bare absolute image path from being exposed to client-side
  media detection alongside the marker.
- Marker templates retain their existing absolute or validated workspace-relative
  path behavior. Clients consuming marker-configured replies must use
  `delivery_marker`. Without a template, the generic outbox reply still returns
  an absolute `delivery_path`; without an outbox, the standard MCP image block
  remains available. No runtime dependency or storage rule changes.
- A live Discord v0.8.4 chat confirmed incoming images under
  `<workspace>/discord_files/<uuid>_<name>.jpg`, followed by successful `capture`
  and `add_attachment`. Setup, security and deployment examples record that
  result separately from synthetic Noetrail tests.

The deployed ZeroClaw build was reported to preserve `FILE` markers, whereas
the published v0.8.4 history canonicalizer explicitly exempts `IMAGE` payloads
only. Noetrail tests cover its marker-only response contract; repeat delivery
and the next model turn in the actual build to verify the complete client path.
See [ZeroClaw setup](../integrations/zeroclaw-setup.md).

## Install

```sh
uvx --from 'noetrail==0.10.0a6' noetrail quickstart
```

The same CI-built wheel and source distribution are distributed through
[GitHub](https://github.com/patsch1/noetrail/releases/tag/v0.10.0a6),
[PyPI](https://pypi.org/project/noetrail/0.10.0a6/), and
[TestPyPI](https://test.pypi.org/project/noetrail/0.10.0a6/).

## Upgrade and rollback

Select 0.10.0a6 and restart the MCP process. Existing marker arguments remain
valid; clients that reconstructed a marker from `delivery_path` must copy
`delivery_marker` instead. The shipped prompt and portable skill describe this
contract. Package publication changes no cluster or live client configuration.

Rollback selects 0.10.0a5 without a data migration, but restores the redundant
bare path and can reintroduce client-side request inflation. All stored images
and entries remain unchanged by this read-only output fix.
