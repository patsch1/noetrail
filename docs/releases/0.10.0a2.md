# Noetrail 0.10.0a2

This alpha updates the public documentation and adds synthetic materials for a
small usability pilot. Runtime behavior is unchanged from 0.10.0a1.
The current core schema is 12; no migration is needed when upgrading from
0.10.0a1.

## Changes

- A shorter README leads with purpose, installation, and a working MCP setup.
- The uvx configuration starts the MCP server through uvx instead of assuming
  quickstart installed a global `noetrail-mcp` command.
- Project descriptions state the actual alpha status, AI authorship, lexical
  retrieval limits, and AI-client privacy boundary.
- The pilot kit contains fictional Obsidian notes, a generated test image,
  a saved view, participant tasks, and an anonymous scorecard. Human pilot
  results are still pending.
- Release consistency accepts a valid calendar date for published changelog
  entries and rejects duplicate version headings and invalid dates.

## Install

```sh
uvx --from 'noetrail==0.10.0a2' noetrail quickstart
```

The same CI-built wheel and source distribution are distributed through
[GitHub](https://github.com/patsch1/noetrail/releases/tag/v0.10.0a2),
[PyPI](https://pypi.org/project/noetrail/0.10.0a2/), and
[TestPyPI](https://test.pypi.org/project/noetrail/0.10.0a2/). GitHub also carries
checksums, the bill of materials, and verifiable build provenance.

## Compatibility and limits

Python 3.11 through 3.14 and the dependency-free runtime are unchanged. CLI,
MCP tools, schema packs, and stored entries have the same behavior as 0.10.0a1.
See the [first-alpha notes](0.10.0a1.md) for features, schema compatibility,
and known limitations. The package remains an alpha.

## Upgrade and rollback

From 0.10.0a1, select the new package version; no data migration or deployment
configuration change is required. Program rollback selects 0.10.0a1 again.
For an older data schema, preview an explicit migration and retain matching
backups of both data and configuration roots before applying it. Follow
[backup and restore](../backup-restore.md).
