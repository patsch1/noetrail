# The Noetrail mark

An `N` drawn as a trail: four waypoints joined by a thin line, the last one
left open. The shape is the product's own structure -- entries with stable IDs,
connected by typed relations -- and the open waypoint is the entry not written
yet. A vault you keep walking, not an archive you closed.

Thin line, heavy dots, from the way a route is drawn on a walking map. It reads
as a path before it reads as a letter, which is the half of the name that a
plain letterform would lose.

| File | Use it for |
| --- | --- |
| `noetrail-mark.svg` | the default, teal, fixed colour |
| `noetrail-mark-currentcolor.svg` | anywhere the surrounding text colour should win -- inline SVG, dark themes, terminals |
| `noetrail-mark-small.svg` | 16-24 px. Thicker strokes and larger dots on purpose: scaling the default down turns it into a smudge |
| `noetrail-lockup.svg` | mark plus wordmark, for a header or a slide |

The teal is `#1D9E75`. It is deliberately not blue: blue is what cloud and AI
products use, and this one is local-first and file-based.

The wordmark in the lockup is live text in a system font stack, so it renders
slightly differently per machine. Converting it to outlines needs a chosen
typeface, which is a decision nobody has made yet.
